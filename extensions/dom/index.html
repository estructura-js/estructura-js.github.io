DOM

Descripción

Manipula el DOM. Realiza consultas, obtiene y establece propiedades (incluyendo style y dataset) de forma unificada, mediante selectores CSS (DOMQuery), nodos únicos (Node) o listas de nodos (Nodes).

Librería: estructura.dom.js

Compatibilidad: ES5+

Estado: RC2

Licencia: AGPL v3

Importación:
<!-- EXTENSIÓN: Estructura / DOM -->
<script src="https://estructura.okzgn.com/extensions/dom/estructura.dom.js"></script>

Demo en vivo

Haga clic, doble clic o clic derecho en cualquier elemento de la página. La demo lee el color y el fondo del elemento con .style(), los copia en el recuadro siguiente y muestra el tipo de evento y la etiqueta del elemento.

Último evento: ninguno

Documentación

1. Uso básico

Seleccione elementos del DOM mediante un selector CSS en un String que empiece por > (DOMQuery), un nodo (Node) o una lista de nodos (NodeList o HTMLCollection). El prefijo > indica a la librería que el texto es un selector CSS con el que debe buscar en el documento. La búsqueda se repite en cada llamada a un método, así que refleja el estado actual del documento.

  • Un String sin >, null, document, window o un array no son objetivos válidos: el resultado no tiene métodos y llamar a uno lanza un TypeError.
  • Al pasar un nodo directamente, se reconoce cualquier elemento (HTML, SVG como <path>, elementos personalizados…) y los nodos de texto y comentario.
// Seleccionar elementos y aplicar cambios
_dom('> .mi-clase').set('id', 'nuevo-id');
_dom('> div').style('backgroundColor', 'red');

// Obtener valores (un array, con un valor por elemento)
var ids = _dom('> #mi_elemento_con_id').get('id');

// Con Node
_dom(document.body).each(function(element, index){ console.log('Body:', element); });

// Con Nodes
var classes = _dom(document.getElementsByClassName('miClase')).get('className');

2. Métodos principales

Encadenamiento: .each() y las escrituras (.set(), y .style()/.data() cuando reciben value) retornan el mismo objeto, por lo que pueden encadenarse. Las lecturas (.get(), y .style()/.data() sin value) retornan un array (Array) con un valor por elemento. .set() sin value (o con undefined) también se comporta como una lectura y retorna un array.

_dom('> .caja')
	.set('title', 'Caja')
	.style('color', 'blue')
	.data('estado', 'activa')
	.each(function(element, index){ console.log(index, element); });

.each(callback)

Itera sobre cada elemento seleccionado del DOM. El callback recibe el elemento y su índice. Retorna el mismo objeto para encadenar.

_dom('> li').each(function(element, index){
	console.log('Elemento ' + index + ':', element);
});

.get(property)

Obtiene el valor de una propiedad de todos los elementos del DOM seleccionados. Soporta acceso anidado mediante puntos. Retorna un array (Array) con los resultados. Las rutas style.* siguen la misma regla de lectura que .style().

var valores = _dom('> input').get('value'); // Un valor por cada input
var primerValor = valores[0];
var clases = _dom('> div').get('className');
var estilos = _dom('> main').get('style.color');

.set(property, value)

Establece el valor de una propiedad en todos los elementos del DOM seleccionados. Soporta acceso anidado mediante puntos. El valor pasa antes por _dom.sanitize (ver Sanitización). Retorna el mismo objeto para encadenar.

_dom('> input').set('value', 'Hola Mundo');
_dom('> body').set('style.background', 'yellow');

.style(property, value)

Manipula estilos CSS. Con value, aplica el valor como estilo inline y retorna el mismo objeto para encadenar. Sin value, retorna un array (Array) con el estilo inline de cada elemento; si el estilo inline está vacío, se usa el valor computado (getComputedStyle). Acepta nombres de propiedades en camelCase (ej. backgroundColor) y en kebab-case (ej. background-color). Las propiedades personalizadas de CSS (--mi-variable) no se admiten: use style.setProperty() y getPropertyValue() dentro de .each().

_dom('> .caja').style('color', 'blue');
var colores = _dom('> .caja').style('color'); // Array: estilo inline o, si está vacío, el computado

.data(property, value)

Manipula el dataset. Permite leer y escribir propiedades del dataset con o sin el prefijo data-; los nombres con guiones se convierten automáticamente a camelCase. Con value, escribe (el valor se guarda como texto, igual que en dataset) y retorna el mismo objeto para encadenar. Sin value, retorna un array (Array) con el valor de cada elemento.

_dom('> div').data('user-id', '456');
var ids = _dom('> div').data('user-id'); // Array con el valor de cada div

3. Sanitización

Toda escritura con .set() pasa por la función _dom.sanitize(value, ctx) antes de asignarse, donde ctx es { type: 'property', name, element } y name es la clave final de la ruta. La función retorna el valor que finalmente se escribe. Las escrituras con .style()/.data() (o rutas style.*/dataset.*) no pasan por ella.

Qué se filtra por defecto:

  • En propiedades de URL (href, src, action, formaction, xlink:href, poster, cite, background), los esquemas javascript: y vbscript: se neutralizan: se escribe '' y se emite un console.warn.
  • data: solo se permite en src y poster, y únicamente para data:image/, data:video/ o data:audio/.
  • Antes de comparar el esquema se eliminan espacios y caracteres de control y se pasa a minúsculas, ya que los navegadores aceptan variantes como java\tscript:.

Qué no se filtra, y por qué: textContent (ya es seguro), value y checked, atributos booleanos, className, id, style.*, dataset.* y aria-*, porque no ejecutan código. Los sinks HTML (innerHTML, outerHTML, srcdoc) pasan sin cambios: filtrar HTML de forma fiable requiere un parser completo, por lo que se delega en una librería especializada.

Reemplazar o extender: asigne su propia función a _dom.sanitize. Para conservar las reglas por defecto, guarde la original y llámela desde la nueva. Asignar una función que retorne value sin cambios desactiva el filtro.

// Conectar DOMPurify (cargado previamente en la página) para los sinks HTML,
// manteniendo las reglas por defecto
var sanitizeDefault = _dom.sanitize;
var htmlSinks = { innerHTML: true, outerHTML: true, srcdoc: true };

_dom.sanitize = function(value, ctx){
	if(htmlSinks[ctx.name]){ return DOMPurify.sanitize(String(value)); }
	return sanitizeDefault(value, ctx);
};

var htmlDelUsuario = '<img src="x" onerror="alert(1)">';
_dom('> #contenido').set('innerHTML', htmlDelUsuario); // Escribe la imagen sin onerror
_dom('> a').set('href', 'javascript:alert(1)'); // Escribe '' y avisa en consola

4. Características técnicas

Estilo computado solo si hace falta: al leer un estilo, se retorna primero el valor inline y solo se llama a getComputedStyle cuando este está vacío.

Normalización de rutas: se eliminan todos los espacios de la ruta, y los puntos al inicio o al final (' style.color. ' equivale a 'style.color').

Rutas inexistentes: si un tramo intermedio de la ruta no existe, la lectura devuelve undefined para ese elemento y la escritura no hace nada.

Errores: no llegan a quien llama como excepción. El núcleo de Estructura los captura y los muestra en la consola con hasta un segundo de retraso, y el método retorna el objeto de métodos en lugar de un array. Ocurren con una propiedad vacía o que no es un String, con un selector CSS no válido, con una ruta style/dataset que no tiene exactamente un nivel más ('style.color' es válida; 'style' y 'style.a.b' no) y cuando el callback de .each() lanza un error, lo que además detiene la iteración.
