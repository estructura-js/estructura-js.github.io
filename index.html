Description

Estructura is a lightweight, dependency-free JavaScript framework that lets you assign functions to be automatically attached to custom or extended data types, based on one or more arguments.

Its goal is to provide a solid foundation for programming in JavaScript in the face of the language’s well-known type quirks.

Read more

It is a lightweight, dependency-free runtime solution that requires neither TypeScript nor compile-time type checking, although the npm package includes type declarations for those who work with TypeScript. It lets you identify any data type, create custom types, organize them, and use them knowing that the dispatcher will deterministically attach the registered functions to their corresponding types, whether custom or predefined. It prioritizes low dispatch cost and is compatible with ES3 (1999) and later.

Performance: each call to the dispatcher costs on the order of microseconds. The cost grows with the number of arguments, with the number of types detected per argument, and with subtype functions, which run on every call. Recommendations: reuse the result of _e(value) when calling its methods several times, keep _e.subtype() functions lightweight, and avoid unnecessarily deep subtype chains.

How to use

Import: 
  • npm install estructura-js

// ESM (the package includes type declarations for TypeScript)
import _e from 'estructura-js';

// CommonJS
const _e = require('estructura-js');
  • <!-- UMD / CDN: Unpkg -->
<script src="https://unpkg.com/estructura-js"></script>
  • <!-- ESM / CDN: Unpkg -->
<script type="module">
    import _e from 'https://unpkg.com/estructura-js/dist/estructura.esm.mjs';
</script>

Extensions

The extensions are a modular set of libraries for frontend development, built on the Estructura core. They are published as release candidates (RC) under the AGPL v3 license, with a commercial license available.

Read more

They include building blocks such as an HTTP client, SPA routing, reactivity, DOM control, events, logic orchestration, declarative or asynchronous components, and an in-browser SQLite database. Unified on top of the multiple-dispatch core, they form a lightweight stack with no external dependencies, except SQLite Frontend, which uses the official SQLite WASM build. There are only two dependencies between them: Components requires HTTP, and Handlers requires Events.
