Descripción

Estructura es un framework de JavaScript ligero y sin dependencias que te permite asignar funciones que se vincularán automáticamente a tipos de datos personalizados o extendidos, basándose en uno o múltiples argumentos.

Diseñado para ofrecer una base sólida al programar en JavaScript, superando sus conocidas peculiaridades nativas en el manejo de tipos («type quirks»). Es una solución de tiempo de ejecución («runtime») ligera, sin dependencias, sin TypeScript, sin verbosidad ni las limitaciones de la verificación de tipos en tiempo de compilación («compile-time»). Proporciona la capacidad de identificar claramente cualquier tipo de dato, crear cualquier tipo de dato personalizado, organizarlos y utilizarlos con la garantía de que el despachador («dispatcher») siempre vinculará las funciones especificadas a sus tipos correspondientes o predefinidos. Fue construido con una optimización máxima, ofrece flexibilidad, y fue diseñado teniendo en cuenta una compatibilidad casi universal (ES3+ [1999]).

Extensiones

Las siguientes extensiones oficiales forman un ecosistema modular que cubre todo el desarrollo fundamental del frontend/cliente: HTTP, enrutamiento SPA, reactividad, control del DOM, eventos y componentes declarativos o asíncronos. Unificadas sobre el núcleo de despacho múltiple, ofrecen un stack completo, ligero y sin dependencias para construir aplicaciones complejas de extremo a extremo, desde prototipos pequeños hasta sistemas de mayor escala.

Extensiones/librerías y documentaciones disponibles:
  • HTTP — (RC1, ES3/ES5+, AGPL v3)
  • DOM — (RC1, ES5+, AGPL v3)
  • Events — (RC1, ES5/ES6+, AGPL v3)
  • Components — (RC2, ES5/ES6+, AGPL v3)
  • Handlers — (RC2, ES5/ES6+, AGPL v3)
  • Reactive — (RC1, ES6+, AGPL v3)
  • Routing — (RC1, ES6+, AGPL v3)
Para usar las extensiones, importar primero Estructura (framework principal): 
<!-- CDN: Unpkg -->
<script src="https://unpkg.com/estructura-js"></script>
<!-- CDN: JSDelivr -->
<script src="https://cdn.jsdelivr.net/npm/estructura-js"></script>
<!-- CDN: Estructura -->
<script src="https://estructura.okzgn.com/estructura.umd.js"></script>
Vincular reemplazando «extensión» por el nombre de la extensión/librería correspondiente (en minúsculas). 
<!-- CDN: Estructura -->
<script src="https://estructura.okzgn.com/extensions/extensión/estructura.extensión.js"></script>
