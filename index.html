Descripción

Estructura es un framework de JavaScript ligero y sin dependencias que permite asignar funciones que se vincularán automáticamente a tipos de datos personalizados o extendidos, basándose en uno o múltiples argumentos.

Su objetivo es ofrecer una base sólida para programar en JavaScript frente a las conocidas peculiaridades del lenguaje en el manejo de tipos («type quirks»).

Leer más

Es una solución en tiempo de ejecución («runtime»), ligera y sin dependencias, que no requiere TypeScript ni verificación de tipos en tiempo de compilación («compile-time»). Permite identificar cualquier tipo de dato, crear tipos personalizados, organizarlos y usarlos sabiendo que el despachador («dispatcher») vinculará de forma determinista las funciones registradas a sus tipos correspondientes o predefinidos. Prioriza un bajo costo de despacho y es compatible con ES3 (1999) en adelante.

Rendimiento: cada llamada al despachador cuesta del orden de microsegundos. El costo crece con el número de argumentos, con la cantidad de tipos detectados por argumento y con las funciones de subtipo, que se ejecutan en cada llamada. Recomendaciones: reutilizar el resultado de _e(valor) cuando se llame varias veces a sus métodos, mantener ligeras las funciones de _e.subtype() y evitar cadenas de subtipos innecesariamente profundas.

Cómo utilizar

Importación: 
  • <!-- UMD / CDN: Unpkg -->
<script src="https://unpkg.com/estructura-js"></script>
  • <!-- ESM / CDN: Unpkg -->
<script type="module">
    import _e from 'https://unpkg.com/estructura-js/dist/estructura.esm.mjs';
</script>
Ejemplos:
  • Código: Guía de inicio rápido — (Estructura)
  • Código: Registrar asignaciones de funciones/métodos para tipos o subtipos — (Estructura)
  • Código: Registrar definiciones de tipos nuevos/personalizados — (Estructura)
  • Implementación: Interfaz de autenticación para aplicación multiusuario — (Estructura, extensiones: Handlers [Events], DOM, HTTP, Routing)
  • Implementación: Interfaz de punto de venta de servicios y productos — (Estructura, extensiones: Handlers [Events], DOM, HTTP, Routing)

Extensiones

Las extensiones son un conjunto modular de librerías para el desarrollo frontend, construidas sobre el núcleo de Estructura. Se publican como versiones candidatas (RC) bajo licencia AGPL v3, con licencia comercial disponible.

Leer más

Incluyen fundamentos como: cliente HTTP, enrutamiento SPA, reactividad, control del DOM, eventos, orquestación de lógica, componentes declarativos o asíncronos y una base de datos SQLite en el navegador. Unificadas sobre el núcleo de despacho múltiple, forman un stack ligero y sin dependencias externas, salvo SQLite Frontend, que usa la compilación oficial de SQLite WASM. Entre ellas, solo Components depende de HTTP, y Handlers, de Events.
