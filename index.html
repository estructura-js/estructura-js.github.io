Descripción

Estructura es un framework de JavaScript ligero y sin dependencias que te permite asignar funciones que se vincularán automáticamente a tipos de datos personalizados o extendidos, basándose en uno o múltiples argumentos.


Diseñado para ofrecer una base sólida al programar en JavaScript, superando sus conocidas peculiaridades nativas en el manejo de tipos («type quirks»).


Leer más

Es una solución de tiempo de ejecución («runtime») ligera, sin dependencias, sin TypeScript, sin verbosidad ni las limitaciones de la verificación de tipos en tiempo de compilación («compile-time»). Proporciona la capacidad de identificar claramente cualquier tipo de dato, crear cualquier tipo de dato personalizado, organizarlos y utilizarlos con la garantía de que el despachador («dispatcher») siempre vinculará las funciones especificadas a sus tipos correspondientes o predefinidos. Fue construido con una optimización máxima, ofrece flexibilidad, y fue diseñado teniendo en cuenta una compatibilidad casi universal (ES3+ [1999]).

Cómo utilizar

Importación:

  • <!-- UMD / CDN: Unpkg -->
<script src="https://unpkg.com/estructura-js"></script>

  • <!-- ESM / CDN: Unpkg -->
<script type="module">
    import _e from 'https://unpkg.com/estructura-js';
</script>
Ejemplos:
  • Código: Guía de inicio rápido — (Estructura)
  • Código: Registrar asignaciones de funciones/métodos para tipos o subtipos — (Estructura)
  • Código: Registrar definiciones de tipos nuevos/personalizados — (Estructura)
  • Implementación: Interfaz de autenticación para aplicación multiusuario — (Estructura, extensiones: Handlers [Events], DOM, HTTP, Routing)
  • Implementación: Interfaz de punto de venta de servicios y productos — (Estructura, extensiones: Handlers [Events], DOM, HTTP, Routing)

Extensiones

Las extensiones son un ecosistema enterprise-grade modular que fundamenta todo el desarrollo del frontend/cliente.


Leer más

Incluye fundamentos como: cliente HTTP, enrutamiento SPA, reactividad, control del DOM, eventos, orquestación de lógica y componentes declarativos o asíncronos. Unificadas sobre el núcleo de despacho múltiple, ofrecen un stack completo, ligero y sin dependencias para construir aplicaciones complejas de extremo a extremo, desde prototipos pequeños hasta sistemas de mayor escala.

Para usar las extensiones, importar primero Estructura (framework principal): 

  • <!-- CDN: Unpkg -->
<script src="https://unpkg.com/estructura-js"></script>

  • <!-- CDN: JSDelivr -->
<script src="https://cdn.jsdelivr.net/npm/estructura-js"></script>

  • <!-- CDN: Estructura -->
<script src="https://estructura.okzgn.com/estructura.umd.js"></script>
